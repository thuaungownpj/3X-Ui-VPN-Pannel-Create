3X-Ui VPN Server ထောင်နည်း

VLESS • XTLS • HTTPUpgrade • Xray

Auto Configurator

သင့် Data များဖြည့်လိုက်သည်နှင့် အောက်ပါ Command များအားလုံး Auto ပြောင်းလဲသွားပါမည်။

(၁) Cloudflare ချိတ်ဆက်ခြင်း

  • Type: A ကိုရွေးပါ။
  • Name: vpn (သို့မဟုတ် ကြိုက်နှစ်သက်ရာ နာမည်ပေးပါ)
  • IPv4 address: မိမိ VPS ၏ IP (192.168.1.1) ကို ထည့်ပါ။
  • TTL: Auto ထားပါ။
  • အားလုံးပြီးလျှင် Create ကို နှိပ်ပါ။

(၂) VPS Server Create လုပ်ခြင်း

မိမိအသုံးပြုမည့် Cloud Provider (ဥပမာ - DigitalOcean, AWS, GCP) တွင် Ubuntu OS ဖြင့် VPS Server အသစ်တစ်ခု ဖန်တီးပါ။

(၃) VPS Firewall Create လုပ်ခြင်း

  • Create Firewall Rule ကိုနှိပ်ပါ။
  • Name: allow-3xui-vpn
  • Network: default
  • Priority: 1000
  • Direction of traffic: Ingress
  • Action on match: Allow
  • Targets: "All instances in the network" ကို ရွေးပေးပါ။
  • Source filter: IPv4 ranges
  • Source IPv4 ranges: 0.0.0.0/0
  • Protocols and ports: "Specified protocols and ports" ကို အမှန်ခြစ်ပါ။
  • TCP ကို အမှန်ခြစ်ပြီး ဘေးက ကွက်လပ်ထဲတွင် 80, 443, 2053, 8080, 2096, 30000-50000 ဟု ရိုက်ထည့်ပါ။
  • UDP ကို အမှန်ခြစ်ပြီး ဘေးက ကွက်လပ်ထဲတွင် 30000-50000 ဟု ရိုက်ထည့်ပါ။
ရှင်းလင်းချက်: 80/443 သည် SSL လက်မှတ်အတွက်၊ 2053 သည် 3X-UI Panel အတွက်၊ 8080 သည် VPN Key အတွက် ဖြစ်ပါသည်။ အားလုံးဖြည့်ပြီးပါက အောက်ဆုံးရှိ "Create" ခလုတ်ကို နှိပ်ပါ။

(၄) 3X-Ui Install လုပ်ခြင်း

VPS Server ကို Terminal ဖြင့်ချိတ်ဆက်ပါ။ ထို့နောက် အောက်ပါ Command များကို တစ်ကြောင်းချင်းစီ ရိုက်ထည့်ပါ။

bash - setup 3x-ui
sudo apt update
sudo apt upgrade -y
sudo -i
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
  • SQLite နှင့် PostgreSQL Database ရွေးခိုင်းရင် 1 ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Would you like to customize the Panel Port settings? ရွေးခိုင်းရင် y ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Please set up the panel port: ရွေးခိုင်းရင် 2053 ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Choose SSL certificate setup method: ရွေးခိုင်းရင် 1 ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Please enter your domain name: ရွေးခိုင်းရင် sub.customdomain.com ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Please choose which port to use (default is 80): ရွေးခိုင်းရင် 80 ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Would you like to modify --reloadcmd for ACME? (y/n): ရွေးခိုင်းရင် n ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Would you like to set this certificate for the panel? ရွေးခိုင်းရင် y ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Pannel Menu ပြန်ဖော်ချင်ရင် x-ui ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Pannel URL Link ကြည့်ချင်ရင် 11 ဟုရိုက်ပြီး Enter နှိပ်ပါ။
  • Pannel UserName Password ပြန်ပေးချင်ရင် 7 ဟုရိုက်ပြီး Enter နှိပ်ပါ။

(၅) Panel Setting ပြင်ဆင်ခြင်း (vless + httpupgrade)

Panel ၏ ဘယ်ဘက် ဘေးဘား (Left Sidebar) ရှိ "Inbounds" ဆိုသည့်နေရာကို နှိပ်ပါ။

Basics Tab တွင် ပြင်ရန်

  • Remark: VLESS-HTTPUPGRADE (မိမိမှတ်မိမည့်အမည် ပေးနိုင်ပါသည်)
  • Protocol: vless ကို ရွေးပါ။
  • Port: 8080 ဟု ရိုက်ထည့်ပါ။
  • Total Flow (GB): ဗလာ (ဘာမှမထည့်ဘဲ) ထားလိုက်ပါ။
  • Expiry Date: ဗလာ ထားလိုက်ပါ။

Stream Tab တွင် ပြင်ရန်

  • Transmission: ပုံထဲမှာ RAW ဖြစ်နေပါတယ်။ အဲဒါကို နှိပ်ပြီး httpupgrade ကို ရွေးချယ်ပေးပါ။
  • Path: httpupgrade ကို ရွေးလိုက်တာနဲ့ Path ဆိုတဲ့ ကွက်လပ်အသစ် ပေါ်လာပါလိမ့်မယ်။ အဲဒီနေရာမှာ /xray ဟု ရိုက်ထည့်ပေးပါ။ (အစက မျဉ်းစောင်းလေး / ပါဖို့ အရေးကြီးပါတယ်)
  • Host: နေရာတွင် မိမိ၏ subdomain vpn.example.com ကို ထည့်ပါ။

(၆) Panel Setting ပြင်ဆင်ခြင်း (Outline)

Panel ၏ ဘယ်ဘက် ဘေးဘား (Left Sidebar) ရှိ "Inbounds" ဆိုသည့်နေရာကို နှိပ်ပါ။

Basics Tab တွင် ပြင်ရန်

  • Remark: Outline (မိမိမှတ်မိမည့်အမည် ပေးနိုင်ပါသည်)
  • Protocol: shadowsocks ကို ရွေးပါ။
  • Port: 41234 (လုံခြုံရေးအတွက် 30000 နဲ့ 50000 ကြားက Port တစ်ခုကို သုံးထားတာပါ။)
  • Total Flow (GB): ဗလာ (ဘာမှမထည့်ဘဲ) ထားလိုက်ပါ။
  • Expiry Date: ဗလာ ထားလိုက်ပါ။

Stream Tab တွင် ပြင်ရန်

  • Transmission: RAW (raw ပဲထားပေးပါ)
  • Proxy Protocol: အားလုံးကို ပိတ် (Disable / Off) ထားပါ။
  • HTTP Obfuscation: အားလုံးကို ပိတ် (Disable / Off) ထားပါ။

Security Tab တွင် ပြင်ရန်

  • Security: None ကိုပဲ ရွေးထားပါ။ (Shadowsocks က သူ့ဘာသာ Encryption လုပ်ပြီးသားဖြစ်လို့ သီးသန့် TLS/Reality တွေ ထပ်ခံစရာ မလိုပါဘူး။)

Sniffing Tab တွင် ပြင်ရန်

  • Enabled: ဖွင့် (On/Enable) လိုက်ပါ။
